# Big-Data-Processing-with-Databricks-Spark
Processed large-scale NYC taxi trip data from 2015 to 2022 using Databricks and Apache Spark. This involved loading yellow and green-colored taxi datasets, cleaning unusual trip records, combining datasets with different schemas, joining location data, running SparkSQL business analysis, and building Spark ML regression models for useful insights.

Overview of Key Stages of the whole process, Data Source Exploration, Explanation of the Different Steps including Data Upload in Azure Cloud Storage, Data Ingestion and Preparation, Comparison of Parquet and CSV Formats, Data Analysis, Data Cleaning, Data Transformation and Combination, and business insights, followed by Machine Learning steps - Baseline Model Creation, Data Splitting, Feature Engineering and Preprocessing, Preprocessing Pipeline,  Data Processing in Chunks, Model Training and Evaluation and Results can be found in the report posted in this repo - [Data processing on big dataset with Databricks Spark.pdf](https://github.com/NaynaJahan/Big-Data-Processing-with-Databricks-Spark/blob/main/Data%20processing%20on%20big%20dataset%20with%20Databricks%20Spark.pdf)
